1. アプリについて

Auto BGM Uploaderは、管理者本人が YouTube動画を自動投稿するための個人用ツールです。

2. 取得・利用するデータ

YouTube APIを通じてチャンネルID、 チャンネル名を取得し、投稿先の確認に利用します。 また、動画アップロード権限を使用します。

3. データの保存

Google OAuthの認証情報は管理者の環境と GitHub Actions Secretsに保存します。 公開Webサイトには保存しません。

4. 第三者サービス

自動投稿処理にはGoogle YouTube APIと GitHub Actionsを使用します。 取得したGoogleユーザーデータを 広告目的で販売・提供することはありません。

5. データの削除と連携解除

管理者は保存済み認証情報を削除できます。 Googleアカウントのアクセス管理画面から アプリの権限を取り消すこともできます。
